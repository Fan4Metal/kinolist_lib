# Kinolist Lib

[English version](README.en.md)

Kinolist Lib — консольная программа для Windows (`kl`), которая формирует списки фильмов в формате docx и записывает сведения о фильмах в теги mp4. Данные о фильмах берутся из неофициального API Кинопоиска (kinopoiskapiunofficial.tech).

## Возможности

- Списки фильмов в формате docx с постерами (шаблоны A4 и A5) или в виде простого нумерованного списка.
- Формирование списков по названиям из командной строки, из текстового файла или по mp4-файлам в каталоге.
- Запись полной карточки фильма (название, год, рейтинг, страны, описание, режиссёры, актёры, постер, жанры, id Кинопоиска) в теги mp4.
- Формирование списков без сети по ранее записанным тегам, в том числе по файлам, на которые указывают ярлыки Windows (`.lnk`).
- Переименование файлов с торрент-именами в формат `Название (год).ext`.
- Кэширование ответов API на один час.

## Требования

- Windows 10 или новее.
- Python 3.13 или новее и [uv](https://docs.astral.sh/uv/) для запуска из исходников.
- Токен API с сайта [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech).

## Установка

### Установщик

Установщик (`Kinolist_Lib <версия> Setup.exe`) размещает программу в профиле пользователя, добавляет её в `PATH` и регистрирует три команды контекстного меню Проводника: список по тегам для каталога, запись тегов для файла mp4 и список по файлу txt.

### Из исходников

```
git clone <адрес репозитория>
cd kinolist_lib
uv sync
```

После этого команда `kl` доступна через `uv run kl`.

## Настройка

Токен API читается из файла `config.py`, расположенного рядом с программой:

```python
KINOPOISK_API_TOKEN = "ваш-токен"
```

## Использование

| Команда | Описание |
|---|---|
| `kl -m "Terminator" "Terminator 2" KP~319` | Список по указанным названиям; `KP~id` задаёт id Кинопоиска напрямую. |
| `kl -f movies.txt -o movies.docx` | Список по названиям из текстового файла, по одному в строке. |
| `kl -l [каталог]` | Список по именам mp4-файлов в каталоге. |
| `kl --loc [каталог]` | Список только по тегам mp4-файлов, без обращения к сети. |
| `kl -t [файл или каталог]` | Запись тегов в файл mp4 или во все mp4-файлы каталога. |
| `kl -t file.mp4 -kp 406` | Запись тегов фильма с указанным id Кинопоиска. |
| `kl --cleartags [файл или каталог]` | Удаление всех тегов. |
| `kl -r *.mp4` | Переименование файлов после подтверждения. |

Модификаторы: `-o` выходной файл, `-s` сокращённые описания, `--txtlist` дополнительный txt-список, `-nf` простой формат списка, `-g` жанры в списке, `--a5` шаблон A5, `--sort` порядок файлов для `--loc` (`date`, `date_r`, `datem`, `datem_r`, `name`, `name_r`), `--test` поиск без создания списка, `--nocache`, `--clearcache`.

Полная справка: `kl --help`.

## Формат тегов

Данные хранятся в стандартных атомах mp4 (`©nam`, `©day`, `©gen`, `desc`, `ldes`, `covr`) и в свободных атомах `----:com.apple.iTunes:*` (`DIRECTOR`, `Actors`, `kpra`, `countr`, `kpid`, `genre`). Рейтинг в `kpra`, начинающийся с `i` (например, `i6.7`), интерпретируется как рейтинг IMDb. Формат совместим с файлами, протегированными предыдущими версиями.

## Разработка

```
uv run pytest
uv run ruff check .
uv run ruff format .
```

Для тестов тегов требуется `ffmpeg` в `PATH`; при его отсутствии они пропускаются.

## Сборка

```
uv run python tools/make_release.py
```

Сценарий собирает каталог `dist\kl` с помощью PyInstaller и, если установлен Inno Setup 6, установщик `dist\Kinolist_Lib <версия> Setup.exe`. Параметр `--no-installer` ограничивает сборку каталогом. Версия берётся из `kinolist/__init__.py` и подставляется в ресурс версии exe и в установщик.
